# Python To-Do List

This is my first project for the DecodeLabs Python Programming internship.

## About the Project

I created a simple To-Do List program using Python. It allows the user to add tasks and view the tasks that were added.

## Features

* Add a new task
* View all added tasks
* Shows a message when there are no tasks
* Exit the program
* Handles invalid menu choices

## Python Concepts Used

* Lists
* `append()`
* `while` loop
* `for` loop
* `if-elif-else`
* User input
* `print()`

## How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in VS Code or any Python editor.
3. Run the following command:


python todo_list.py


4. Select an option from the menu and follow the instructions.
