# Python General Knowledge Quiz

This is my fourth project for the DecodeLabs Python Programming internship.

## About the Project

I created a simple General Knowledge Quiz using Python.

The program randomly selects 5 questions from a set of questions and asks the user to answer them. At the end, it shows the total score.

## Features

- Randomly selects questions for each quiz
- Asks 5 questions in each attempt
- Checks the user's answers
- Keeps track of the score
- Shows the correct answer when the answer is wrong
- Displays the final score
- Gives a message based on the score

## Python Concepts Used

- `random` module
- Lists
- Dictionaries
- `random.sample()`
- `for` loop
- `if-else`
- Variables
- User input
- String methods

## How It Works

1. A list of questions and answers is created.
2. The program randomly selects 5 questions.
3. The user enters an answer for each question.
4. The program checks the answer.
5. The score increases for every correct answer.
6. The final score is displayed at the end.
